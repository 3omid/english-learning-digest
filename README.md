# صفحه‌ی آموزش زبان انگلیسی (روزنامه‌وار)

یک صفحه‌ی خودکار (۲ بار در روز - ساعت ۸ صبح و ۵ عصر به وقت تورنتو) که دقیقا مثل یک روزنامه، محتوای آموزش زبان انگلیسی رو در ۴ بخش نشون می‌ده: گرامر، واژگان، رایتینگ و نگارش، لیسنینگ و اسپیکینگ.

منابع: VOA Learning English (Everyday Grammar, Ask a Teacher, Education Tips, How to Pronounce, English in a Minute) و Merriam-Webster (Word of the Day) - به‌علاوه‌ی نکته‌های تازه‌ای که هر بار هوش مصنوعی (Gemini) تولید می‌کنه، و یک تست چهارگزینه‌ای چرخشی.

منتشر می‌شه روی GitHub Pages، مستقل از پروژه‌ی خواهرش persian-news-digest.

## راه‌اندازی

در Settings > Secrets and variables > Actions این secret رو اضافه کن: GEMINI_API_KEY (کلید رایگان از aistudio.google.com/apikey). بعد در Settings > Pages منبع رو روی GitHub Actions بذار.
